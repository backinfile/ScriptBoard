# 拖入文件夹时保留相对目录结构

主机文件页面允许维护员和系统管理员把文件夹拖入当前目录。浏览器递归读取拖入目录中的普通文件，并为每个文件提交以斜杠分隔的相对路径；空目录不单独创建。单批仍限制为最多 100 个文件、单文件最大 1 GiB、请求最大 2 GiB。

相对路径由 Host Files 模块逐段校验，拒绝绝对路径、父目录跳转、空路径段、平台危险名称和 ScriptBoard 保留名称。模块在同一个批次事务中暂存全部内容、创建缺失父目录并提交文件；提交或后续元数据记录失败时，恢复被覆盖文件并移除本批次创建的文件与空目录。Web 与特权操作 Broker 只传递相对路径元数据，不自行复制目录事务逻辑。

普通文件选择和单层多文件上传保持原有行为。冲突检查使用完整相对路径；重命名只改变发生冲突文件的末级名称并保留其父目录。该决定取代 ADR 0037 中“不支持浏览器文件夹上传”的限制，不引入归档自动解压、符号链接或其他特殊文件上传。
