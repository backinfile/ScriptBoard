# 计划使用五段 cron 和分钟级粒度

内置调度器只接受标准的五段 cron 表达式（分钟、小时、日、月、星期），最小粒度为一分钟。字段支持数字、`*`、`,`、`-`、`/`，月份还支持 `JAN`–`DEC`，星期还支持 `SUN`–`SAT`，英文名称不区分大小写。明确拒绝秒字段、`?`、所有 `@` 快捷语法，以及 `TZ` / `CRON_TZ` 前缀。

表达式一律按 ScriptBoard 实例的调度时区执行，计划项不能单独覆盖时区。日期与星期字段同时受限时沿用标准 cron 的 OR 语义，界面必须明确提示这一点。

页面提供每 15 分钟、每小时、每天和每周一等常用预设，并保留高级表达式输入与工作日、每月首日示例。浏览器在输入后调用与最终保存相同的服务端解析器，展示本地化摘要、实例时区和未来五次触发时间；无 JavaScript 时由显式预览提交完成相同检查并保留全部表单值。实时预览不可用不阻止最终提交，但最终保存必须重新验证；无效或无法产生未来时间的配置不能保存。

历史数据不保留宽松语法兼容层。服务启动或调度时发现已启用的非法表达式，应立即停用对应计划并记录审计事件，避免执行含义不明确的配置。
