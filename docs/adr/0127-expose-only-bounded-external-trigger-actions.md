# 仅开放有界的外部触发动作

> 凭据保存部分已被 [ADR-0143](./0143-seal-recoverable-secrets-with-an-external-host-key.md) 取代；External Trigger Key 现只显示一次并只保存不可逆 verifier，可恢复的远程来源秘密使用 State Root 外部主密钥密封。

ScriptBoard 提供一个入站 `POST /trigger` 接口，但不开放通用 REST API、任意脚本路径、命令、参数或变量名。管理员和维护员先创建带独立启停状态与可选到期时间的 External Interface Key，再在 Key 下配置以 `name` 唯一区分的功能条目。条目只能是向预先指定的日志文件追加一行受限文本、向固定目录上传单个文件、启动一个已有 Quick Run，或按 Boolean、整数范围、枚举、短文本长度与正则约束修改一个非密码变量。

SQLite 只保存完整 Key 的 SHA-256 摘要、公开标识和末尾提示，用于鉴权和列表展示；完整 Key 使用独立主密钥进行 AES-GCM 加密，并保存在 State Root 的私有密钥文件中。只有管理员和维护员可通过禁止缓存的受保护页面解密和复制，观察员与操作员无权访问。请求必须使用 `Authorization: Bearer`，不接受可能进入访问日志、浏览器历史或监控系统的查询参数凭据；响应禁止缓存。Key 到期在每次请求鉴权时判定，等同自动停用；Key 与条目任一停用都拒绝触发。每个 Key 固定限制为每分钟 60 次、最多 4 个并发请求。

日志文件在配置与调用时均通过 Host Filesystem 的绝对路径、保护目录、链接与普通文件边界校验，每次调用以单次追加写入 UTC 时间、可选分类和消息；上传重新校验已存在且可写的固定目录、单文件字段、请求体、文件字节数、文件名、扩展名白名单和同名策略；Quick Run 每次加载当前配置且不接受调用方参数；变量每次确认目标仍存在且不是密码变量，审计不记录旧值或新值。被条目引用的 Quick Run 和变量不能删除，变量也不能改名或转为密码变量。

每次已解析到 Key 与条目的调用都写入有界请求记录和审计，保存 Key/条目标识、动作、结果、HTTP 状态、耗时、上传字节数或 Run ID，但不保存完整 Key、上传正文或变量值。本决策以一个窄而可审计的入站能力取代 [ADR-0063](./0063-do-not-offer-a-public-api-in-the-mvp.md) 的全面不开放结论；其余通用公开 API 仍不在范围内。
