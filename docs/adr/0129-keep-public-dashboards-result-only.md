# Keep public dashboards result-only

Public custom dashboards render only card names, derived values, freshness, website availability, latency, SSL status, and Docker Registry image results. Source URLs, request headers, JSON paths, formulas, monitor identifiers, Registry endpoints, usernames, and raw errors remain authenticated configuration because making a dashboard shareable must not also publish credentials or integration structure; public rendering therefore resolves references and sanitizes data cards on the server instead of exposing a reusable configuration payload. Registry passwords and tokens are encrypted in the State Root secret store and are never written to the dashboard database or export files.
