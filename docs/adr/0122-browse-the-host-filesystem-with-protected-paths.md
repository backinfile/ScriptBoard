# 浏览主机文件系统并集中保护应用关键路径

ScriptBoard 不再配置受管根目录。文件页以“此主机”为顶层：Windows 枚举可用的本地卷、移动卷和网络卷，Linux 从 `/` 进入；文件、工作目录、快捷执行和计划统一保存规范化绝对路径及平台比较键。最终可访问性仍由服务进程的操作系统身份决定，应用不增加用户 impersonation 或逐目录授权。

`internal/hostfiles` 是唯一解释主机路径的模块。它负责绝对路径规范化、Windows 大小写比较、卷与文件系统识别、隐藏属性、权限和空间检查、文件类型限制、文本读写、下载、回收、执行准备、源日志、路径租约及跨文件系统移动。Web handler、Run Manager、快捷执行和调度器只传递绝对路径，不能自行拼接路径或复制保护判断。文件 Web 路由使用 `path` 查询参数或表单字段，避免 Windows 盘符和 Unix 根路径进入通配路由。

State Root、Install Root、活动配置、管理员密码文件、TLS 私钥及每个文件系统的 ScriptBoard 回收区都是受保护路径。它们在列表中隐藏，直接访问也拒绝；对路径自身、后代，以及包含它的祖先执行编辑、移动、删除、覆盖或执行均失败。符号链接、Junction、重解析点和特殊文件只作为受限条目显示且永不跟随。真实磁盘、普通挂载、网络挂载和临时文件系统可以进入；Linux `/proc`、`/sys`、`/dev` 等内核虚拟文件系统只显示为受限入口。

网页删除不会永久删除。每个源文件系统必须能安全建立带实例所有权标记的私有回收区，删除才可继续；否则拒绝操作。同文件系统移动使用原子重命名。跨文件系统移动是持久化状态机：预扫描并检查空间与受限子项，复制到目标同目录临时项，保留和校验内容与平台元数据，原子提交目标，将源移入源文件系统回收区，最后在一个数据库事务中更新快捷执行与计划引用。提交前失败或取消会清理临时项并保留源；服务重启依据操作记录自动恢复或回滚。路径租约阻止活动 Run 与文件事务相互竞争，进度通过状态端点和 SSE 展示。

在线编辑仍只接受不超过 1 MiB、有效 UTF-8 且不含 NUL 的普通文件，并使用摘要冲突检测、同目录临时文件和原子替换。隐藏文件默认不显示，Windows 同时识别 Hidden 与 System 属性；浏览器快捷访问保存版本化绝对路径，失效或受保护的条目只能移除。

内置 Git 版本保护整体移除，包括设置页、Run 生命周期检查点、路由、数据库状态和 Git 可执行程序配置。磁盘上已有 `.git` 和历史不会被迁移或删除，之后只按普通主机条目处理。

该变更不提供旧版本兼容层。数据库 schema 直接升至 20，只接受全新状态库；任何旧 schema 都在写入前被拒绝。包含 `managed_root`、`git_executable` 的旧 YAML、环境变量或命令行参数同样明确拒绝。管理员必须提供新配置和新的 State Root，旧配置、旧数据库、旧回收区、旧快捷执行、旧计划与浏览器固定项不会自动修改、迁移或删除。

这一决策扩大了执行员的读取范围：执行员能够读取服务身份可读、且不受保护策略限制的普通主机文件。这是整机文件页与现有固定角色矩阵共同产生的明确安全后果；部署者必须相应约束服务身份和可登录用户。

本 ADR 取代 ADR-0003、ADR-0005、ADR-0055、ADR-0071，以及 ADR-0091 至 ADR-0099、ADR-0101 至 ADR-0106 中关于本地 Git 版本保护的决策；其余关于链接不跟随、原子编辑、引用完整性、Run 生命周期和角色权限的决策继续适用，并以本 ADR 的绝对主机路径语义解释。
