# 按操作者意图重组 Web 路由

Web 工作区按监控、资源、配置、历史和设置分组，使用 `/monitor/*`、`/resources/*`、`/config/*`、`/history/*` 与 `/settings/*` 命名空间。根路径、登录成功和品牌入口统一进入 `/monitor`。旧的扁平页面路由不提供重定向、别名或兼容层，以便页面结构、导航语义和测试契约同时收敛。

新建、上传、运行、编辑和保存等聚焦任务必须拥有语义化 GET 地址。无 JavaScript 时这些地址呈现完整服务端页面；启用 JavaScript 时同一内容增强为右侧任务面板，并保留浏览器历史和深链能力。状态修改仍只使用受 CSRF 保护的非 GET 请求。
