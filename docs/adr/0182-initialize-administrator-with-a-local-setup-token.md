# 使用本机令牌完成首次管理员设置

新安装预留唯一 administrator 记录，并在 administrator_setup 保存待初始化状态、令牌摘要和有效期。待初始化账号没有可用密码，登录入口引导至 /setup。已有账号升级时不创建待初始化记录，因此保持原有认证行为。数据库 schema 更新为 68。

启动时将 32 字节随机令牌写入 State Root/secrets/initialization-token，并提供 fragment 形式的初始化链接；令牌有效期 24 小时，未完成设置时每次重启轮换。页面支持手动粘贴与无 JavaScript 提交，启用 JavaScript 时读取 fragment 后立即清除地址栏中的令牌。公网访问不会自行获得令牌。

提交复用现有请求边界、CSRF、限流和密码策略。令牌消费与用户名、Argon2id 密码哈希更新在同一 SQLite 事务中完成，并发提交仅一个成功。成功后删除令牌文件，复用会话签发与审计；会话失败时提示账号已创建并引导登录。数据库状态读取失败时拒绝继续。

显式非空 admin-password-file 完成初始化，并继续保持每次启动的权威覆盖语义；只有用户名覆盖时仍需要设置密码。本机 admin reset 完成待初始化状态并生成原有恢复密码，撤销会话和 MFA。首次设置不改变多用户角色、MFA 自愿注册或既有管理员唯一性约束。

本文取代 ADR-0021 中的新安装随机登录密码交付流程；本机恢复流程保持。
