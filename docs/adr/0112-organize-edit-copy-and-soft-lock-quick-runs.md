# 为快捷执行提供分组、编辑、复制与软锁

快捷执行页采用管理员定义的一层分组来整理条目：每个快捷执行项至多属于一个分组，未选择分组时进入派生的“未分组”区域。分组和组内条目分别排序；移动条目时追加到目标分组，删除分组时按原组内顺序把条目追加到“未分组”，不级联删除。分组默认展开，折叠偏好只保存在当前浏览器。

管理员可编辑快捷执行项的名称、参数模板和超时，但不能通过编辑改写脚本路径或来源关系。复制会创建拥有新 ID 的独立条目，保留脚本配置与可空来源 Run ID，默认解除锁定；复制到原分组时紧随来源项，复制到其他分组时追加。

每个快捷执行项可设置持久化软锁。软锁是防误操作机制而非权限边界：界面禁用编辑与删除，服务端也拒绝相应请求；启动、复制、移动分组、排序以及文件移动触发的系统引用更新继续允许。所有分组、编辑、复制、移动、锁定和解锁操作均写入审计事件。

此决定扩展 [ADR-0111](./0111-create-quick-runs-from-files-or-run-history.md)，不改变快捷执行必须由管理员显式创建以及启动时重新校验脚本、变量和执行器的边界。
