# TLS 验证例外一小时到期且远程汇聚只接受 HTTPS

网站 HTTP/HTTPS 与 WebSocket 探测仍允许管理员为故障诊断临时关闭证书验证，但该选择不再
形成永久布尔配置。Manager 在每次创建或更新时为关闭验证的配置签发一小时例外，保存明确
到期时间；读取和执行配置时只在到期时间之前设置 `InsecureSkipVerify`，到期即自动恢复证书
验证。创建和更新网站监控的审计目标同时记录到期时间，页面在例外有效期间继续显示警告。

旧配置只有 `SkipTLSVerification=true` 而没有到期时间，加载后视为已经到期，不能延续永久
弱校验。导出不把原例外当作长期凭据；再次导入并明确保留关闭验证时由目标实例签发新的
一小时例外。管理员如仍需诊断，必须重新保存配置，从而产生新的审计事件。

远程 ScriptBoard 网站状态汇聚只接受 HTTPS Endpoint，不再接受 HTTP。请求继续使用共享
出站策略、禁止重定向并携带实例级只读能力；HTTPS 要求不能被内网允许开关或环境代理
绕过。未来若需要私有 PKI，应配置宿主信任链，而不是为跨实例 Core 通信增加跳过验证开关。
