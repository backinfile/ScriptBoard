# 在五个操作页面共享一个内容分组目录

快捷执行、计划、变量、文件快捷访问和网站监控使用同一个实例级一层分组目录及全局分组顺序。外部接口分组继续承担访问边界，不接入内容分组。真实分组即使为空也在五页显示；“未分组”由空引用派生，只在有内容时显示并固定在最后。每个页面独立保存浏览器折叠偏好，业务记录在各自分组内独立排序。

为保持 schema 60 数据稳定，`quick_run_groups` 作为共享目录的兼容物理表，原 ID、名称和顺序全部保留；`schedule_groups` 暂时作为计划外键所需的同步影子表。升级时不进行名称猜测：已有计划、变量、文件快捷访问和网站监控均进入“未分组”。网站监控导入导出不携带分组，因此导入项也进入“未分组”。

维护员和系统管理员可维护共享目录。删除真实分组前，界面展示五类内容的影响数量；确认后仅删除容器，并把每类内容按原组内相对顺序追加到该类“未分组”排序域。分组始终只用于组织，不参与授权。
