# Web 完整提供简体中文与美式英语

Web 的导航、标题、状态、动作、表单、错误摘要和日期完整提供 `zh-CN` 与 `en-US` 两种语言。首次请求按 `Accept-Language` 协商：任何中文语言范围选择简体中文，其余选择美式英语；用户可在界面切换，选择由站点级 Cookie 保存。URL 不添加语言前缀，服务端渲染和 JavaScript 增强共享同一语言决定。

领域状态码、配置键、Run ID、原始脚本输出与展开后的技术详情保持稳定英文，避免改变接口和诊断事实。CLI 与 Windows 托盘不进入本次范围，继续只提供简体中文。

此决定取代 [ADR-0081](./0081-ship-a-simplified-chinese-only-mvp.md)。
