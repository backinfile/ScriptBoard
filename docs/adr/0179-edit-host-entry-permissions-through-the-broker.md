# 0179: 通过 Broker 编辑主机条目的平台原生权限

## Status

Accepted

## Decision

文件和目录的更多操作统一提供“设置权限”，取代 Linux 普通文件专用的所有者执行位开关。维护员和系统管理员可以在同一个任务抽屉中查看目标与当前权限；提交属于需要近期认证的 Host Files 写操作，并由特权 Broker 在执行点重新校验规范路径、受保护路径、条目类型与平台参数。ADR-0046 被本决策取代。

Linux 使用 POSIX 权限矩阵编辑 owner、group、others 的 read、write、execute 位，并显示现有所有者和组；目录可以显式递归应用模式。当前版本不提供 chown 或 chgrp。

Windows 使用安全描述符展示所有者、继承状态和 DACL。所有者编辑默认收起；用户可以按账号名或 SID 更换所有者，编辑直接 Allow ACE、添加或移除主体规则、切换继承，并可对目录显式选择子项范围。继承规则只读展示，避免把父目录策略伪装成目标上的直接规则。

递归变更先执行有界预检，拒绝受保护路径、链接、重解析点、特殊文件与过大树；执行期间失败时回滚本次已应用的条目。权限结果不进入数据库，审计只记录动作与目标，不记录完整 ACL 或账号输入。

## Consequences

Linux 的执行权限并入完整权限矩阵，Windows 获得对应的原生 ACL 与所有者入口。界面必须明确平台语义，不能把 POSIX 数字模式映射成 Windows ACL，也不能把 Windows 继承规则静默改写成直接规则。操作仍受 Broker 服务身份在宿主上的实际权限约束。
