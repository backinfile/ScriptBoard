# 使用带格式类型的普通参数变量并支持仅用于展示的密码类型

ScriptBoard 允许管理员预存具名变量并在执行参数中引用。变量具有 `text`、`bool`、`integer`、`float` 或严格 `x.y.z` 的 `version` 类型；类型只在写入时校验格式，不保存最小值、最大值、枚举、长度或正则等业务约束。启动脚本时所有变量仍展开为字符串。

所有变量都按普通数据处理：值以明文形式存入 SQLite。每个变量可设置为密码类型；此标记只让变量页面默认遮罩其值，并允许管理员通过显示按钮临时查看，不提供加密或秘密存储。变量引用必须独占一个参数，不能嵌入其他文本，从而保证变量值不会改变参数数组边界。快捷执行项和计划项保存变量引用并在每次启动时重新解析；Run 同时保存原始模板与当时解析后的实际参数数组，因此修改变量只影响之后的执行。界面必须说明密码类型不是凭据保险库，变量值仍可能出现在实际运行参数与历史记录中。
