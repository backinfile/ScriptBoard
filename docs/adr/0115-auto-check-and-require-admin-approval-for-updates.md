# 自动检查稳定版并要求管理员确认安装

正式 ScriptBoard Release 默认按配置周期检查固定官方仓库的最新稳定版，并在设置页展示当前构建、发布说明、检查错误和安装能力。检查不上传脚本、配置、主机信息或安装标识；网络失败不能影响现有服务。源码开发构建不检查，便携 Release 只提供检查与手工下载入口。

第一版的“自动更新”只表示自动检查，以及管理员一次明确确认后由系统自动完成部署。系统不得静默或定时安装更新。存在活动 Run 时必须拒绝安装且不能停止这些 Run；进入切换前必须同步暂停计划触发并关闭所有新 Run 入口。

此决策取代 ADR-0076。旧式单文件服务安装不迁移、不兼容，第一个包含本能力的正式 Release 必须按新版受管服务布局全新安装，自动更新从后续正式 Release 开始。
