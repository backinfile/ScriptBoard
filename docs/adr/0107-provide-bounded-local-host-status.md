# 提供有界的本机宿主状态

ScriptBoard 将“概览”作为认证后的默认首页，在应用进程内每 5 秒采集一次当前宿主的 CPU、内存、本地文件系统、磁盘 I/O、活动非回环网络接口和 ScriptBoard 进程指标。最近 15 分钟的 5 秒样本只保存在内存中；每个完整自然分钟将平均值与峰值写入现有 SQLite，并固定保留 24 小时。采集使用纯 Go 的跨平台系统接口库，单类指标失败、历史写入失败或数据过期只在概览中明确显示，不阻止核心服务启动或脚本执行。

概览只对采集失败、数据过期以及关键卷低于既有最低可写空间等客观条件标记异常，不为 CPU 或内存设置通用阈值。它不提供通知、自动阻止运行、逐 Run 资源归属、Top 进程、硬件传感器、长期历史、可配置保留期、Prometheus endpoint 或稳定公共 API；这些能力不能借宿主状态模块隐式扩张为通用监控平台。
