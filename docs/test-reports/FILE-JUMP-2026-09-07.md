## 搜索边界

最多返回 100 项、检查 10,000 个条目，使用 3 秒协作式时间预算；在目录读取之间检查取消与预算。单次文件系统读取仍受现有文件访问层/传输超时约束。达到预算或子目录不可读时明确提示结果不完整；不跟随受限制的链接，不索引文件内容。
