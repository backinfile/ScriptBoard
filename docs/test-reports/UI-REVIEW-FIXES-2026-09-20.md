# UI 审查问题修复与本地验收

日期：2026-09-20。起点：dev `38913e9`。本轮修复此前两份独立 UI 评估汇总的问题，并补充镜像版本创建时间倒序。

## 修复结果

| 范围 | 结果 |
|---|---|
| 手机面板编辑 | 标题、摘要、操作分行，编辑按钮可直接点击；手机操作按钮和开关扩大点击区域 |
| 流程状态 | 执行卡不再显示采集卡的“尚未成功刷新”；显示执行历史、成功/失败及尚未执行状态 |
| YAML 错误恢复 | 就地显示原因、定位解析器返回的行号、保留草稿；输入后移除旧错误，不再打开通用 HTTP 错误弹窗 |
| Registry 布局 | 连接与命名空间改为横向布局，桌面关键列无需横向滚动；手机搜索独占一行 |
| 批量范围 | 默认显示数量，展开核对完整列表；保留全部已选仓库提交值 |
| 英文界面 | 面板配置、可见性、权限、操作、流程帮助与校验错误接入中英文；用户填写的内容保留原文 |
| 快捷执行 | 编辑时名称、备注前置；减少重复参数标题；内存额度逐步展开 |
| 二次认证 | 显示可信本地页面的返回目标，不显示任意 URL 或查询参数 |
| 视觉细节 | 压缩单卡页面留白、提高暗色流程按钮及成功状态可读性，折叠长 YAML 参考说明 |
| 镜像版本抽屉 | 按镜像创建时间降序；时间相同时按 tag 升序稳定展示，未知时间置后 |

## 验证

- `go test ./...`：通过。新增排序、字段错误行号、可信返回目标回归测试。
- `go vet ./...`、Windows 构建、Linux amd64 交叉构建：通过。
- `integration/browser` 完整 `npm test`：通过，含外部 Chromium 桌面门禁。
- 最终本地部署的外部 Chromium：7 项主验收通过，15 项补充布局/选择/错误恢复/键盘检查通过，主验收未捕获页面 JS 异常。
- 1440px 桌面、768px 平板、720px 窄桌面、390px 手机：涉及页面无整页横向溢出。720px 是窄视口检查，不代替真实 200% 浏览器缩放。
- 真实版本抽屉测试：乱序服务响应最终显示 `latest, z-new, a-old, unknown`；前两个创建时间相同，旧版本随后，缺失时间最后。
- 对实际计算配色测量：主操作文字对比度约 6.73:1；成功节点与状态文字约 10.40:1。这是指定控件的测量，不代表全站无障碍认证。

## UI 结论与边界

当前布局适合运维工具的配置和状态查看：关键动作不再受手机摘要遮挡，错误修正留在原编辑上下文，镜像关键列与批量范围容易核对。无需整体改版。大量连接/命名空间的数据密度仍可在实际使用后再评估。

未开展完整屏幕阅读器、真实浏览器 200% 缩放或全站色彩审计；Linux 仅交叉构建，本机未做原生 Linux UI 运行。镜像服务未提供创建时间时不推测时间，包括无法取得创建时间的多平台索引，统一放到已知日期之后。
