# 镜像仓库 UI 与卡片折叠验收

## 修改

- 镜像仓库采用数据库页共用的连接侧栏、内容区和页签；选中连接的名称、地址、权限和编辑入口集中展示。
- 命名空间置于内容区可折叠筛选区域；桌面保留完整表格，按内容区宽度自动切换为分行展示。
- 操作记录空状态增加说明和返回镜像入口，移除导致空白区域撑高的旧布局规则。
- 镜像仓库卡片按路径前缀逐级折叠。每张卡片单独保存 localStorage 状态，刷新与局部导航后恢复；存储异常时仍可展开、折叠。
- 镜像详情继续按创建时间倒序，批量预览继续保留完整选择范围。

## 验证

- 原问题复现：1840×764 操作记录空状态连接区异常扩张；布局测量脚本明确失败。
- 重做后外部 Chromium 覆盖 1840、1440、1024、768、390px，两页签均无整页溢出，桌面连接栏与内容区顶部对齐，窄屏顺序排列。
- 实测镜像版本抽屉顺序、选择 20 个镜像的批量预览、面板卡片折叠后的页面重载。
- 新增浏览器回归覆盖嵌套前缀、数量、同名不同卡片隔离、刷新恢复、局部 DOM 替换、无效 JSON 和本地存储禁用。
- Registry/CustomDashboard 相关 Go 测试通过。
- 完整 `integration/browser` 门禁、`go vet ./internal/web` 与 Windows 构建通过；最终部署再次通过 11 组页面和交互检查。
