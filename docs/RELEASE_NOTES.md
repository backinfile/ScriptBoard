# ScriptBoard v2.0.24

## 运行时与权限边界

- Runner 默认使用特权宿主模式，容器与 Kubernetes 访问统一通过 Broker 的受控接口执行；仍可通过配置切换为隔离身份模式。
- 强化 Windows 四服务安装、恢复和 ACL 校验，并修复 SCM 安全门禁的临时目录与安装目录隔离，避免测试触碰真实安装位置。
- 修复脚本运行环境未完整继承父进程变量、Linux 安全概览可能阻塞，以及 Docker 引擎响应较慢时状态探测过早失败的问题。

## 日志、容器与 Kubernetes

- 统一运行日志、服务日志、容器日志和 Kubernetes 日志的查看体验，支持文本下载、移动端布局和更清晰的状态展示。
- 容器与 Kubernetes 监控支持实时局部刷新，列表筛选、固定项目、详情面板和移动端交互更加稳定。
- 修复后台 MySQL 操作与 Shell 会话缓存相关问题，并补充相应回归测试。

## Web 与监控修复

- 修复公开看板 slug URL、网站监控非标准端口、文件回收站入口布局和多处校验/导航问题。
- 简化 Web 工作流和数据库迁移应用逻辑，减少重复代码，同时保持数据库 schema 48 与 updater protocol 2 不变。

## 升级

`v2.0.23` 已使用 updater protocol 2，可直接在“系统设置 → 更新”中升级到本版本。升级前仍建议备份 `config.yaml` 与 State Root；数据库成功由新版本打开后，不要再使用旧版本二进制访问同一 State Root。
