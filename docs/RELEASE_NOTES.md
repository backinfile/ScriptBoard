# ScriptBoard v2.5.2

## 新增功能

- 新增跨平台主机文件权限管理：Windows 可查看和编辑 ACL，Linux 可编辑 POSIX 权限；权限变更继续通过受限 Broker 执行，并保护符号链接和系统路径边界。
- 新增统一共享分组目录：快捷执行、执行计划、变量、文件快捷访问和网站监控现在共用同一套分组，可统一创建、排序、改名和删除。
- 新增 MySQL 数据库备份与清空操作：支持单库备份、批量备份，以及在确认和 step-up 验证后执行“备份并清空”。
- 新增快捷执行启动确认选项：可为指定快捷执行开启二次确认，避免误触启动，同时保持原有计划和接口兼容。
- 新增文件上传冲突处理与重命名抽屉：同名文件可明确选择处理方式，文件列表中的重命名和失败反馈不再打断当前工作区。
- 自定义仪表盘的监控页和公开页新增深色氛围视觉、渐变卡片、状态强调和低动态模式适配；配置页继续保持原有浅色管理界面。

## 功能修改与修复

- 文件快捷访问的分组操作移至页面标题区域，并修复分组保存时的 SQLite 自等待死锁，以及 PJAX 切换后编辑抽屉丢失的问题。
- 修复文件页 deferred PJAX 两阶段加载期间过早启用快捷访问所造成的竞态，较慢环境中打开的编辑抽屉不再被第二阶段清理关闭。
- 优化快捷执行交互：选中项启动后会显示明确确认，活动 Run 导航可直接进入唯一运行详情，长操作菜单可在 Top Layer 中完整滚动。
- 修复 Windows 与 Linux Broker 文件边界判断，正确处理尚不存在的上传或重命名目标，并继续阻止越界主机文件访问。
- step-up 身份验证改为当前页面内的对话框流程，完成敏感操作后返回原工作区。
- 加固 MCP/OAuth：完善客户端注册、令牌撤销、Scope 收窄、失败限流和幂等操作账本，并修正 Windows 服务生命周期边界。
- 修复自定义仪表盘 SVG 渐变定义触发 CSP 错误的问题，并为渐变卡片保留稳定的实体背景回退；浏览器 console 与页面错误门禁恢复为零错误。
- 将请求目标 fuzz 输入约束到服务器真实的 1 MiB HTTP 请求头上限，避免超范围合成输入在 CI 定时 fuzz 结束边界造成伪失败。
- 稳定共享实时数据库的前端契约测试连接，使 release race 门禁在后台写入期间按应用的 SQLite busy timeout 等待，不再产生偶发 `SQLITE_BUSY`。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
