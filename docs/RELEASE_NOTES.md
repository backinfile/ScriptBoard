# ScriptBoard v2.4.3

## 远程主机访问

- 远程 ScriptBoard 主机的状态卡新增“打开 ScriptBoard”入口，可从机器概览直接进入对应管理界面。
- 本机状态卡继续保持本地操作边界，不显示无意义的远程打开按钮。

## Registry 监控稳定性

- Registry 仓库诊断现在会正确处理空仓库，不再把没有镜像的正常响应误判为失败。
- 增强 Registry 响应兼容性和事务测试，减少不同服务实现返回内容差异导致的诊断异常。

## 文档与界面预览

- 更新中英文 README 的机器概览、主机文件、快捷执行与数据库工作台截图。
- README 的数据库说明与当前统一 MySQL、MariaDB 和 Redis 工作台保持一致。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
