# ScriptBoard v2.7.0

## 新增功能

- Host Files 现已支持拖放整个文件夹上传；嵌套目录结构会被保留，冲突预检、重命名、批次回滚与 100 文件上限继续适用于整个上传批次。

## 功能修改与修复

- 删除单个或多个 Host Files 文件后会停留在当前目录，并保留排序、搜索和分页状态；批量移入回收站时也不再因 Broker 审计竞争 SQLite 写锁而失败。
- 修复受管部署中 Broker 导出 kubeconfig 时，临时目录与目标目录位于不同卷会导致替换失败的问题。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
