# ScriptBoard v2.12.0

## 新增功能

- 可视化工作流编排：连接数据与执行顺序，支持参数配置、撤销/重做和一键整理画布。
- 保存可重复运行的执行入口，配置参数、互斥资源标签和运行前确认。
- 自定义 Python、JavaScript、Shell 和 PowerShell 节点，连接构建、镜像与部署步骤。
- 使用算术、分支、汇合和等待节点控制流程，配置失败重试并查看步骤结果与进程日志。
- 导入和导出工作流配置，复用已有编排与自定义节点。

## 升级与使用

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。

执行节点需要主机安装 Python 3；构建、容器和部署节点还需安装相应工具。保存工作流新版本后，编辑执行入口并保存以更新版本绑定。

重试和取消不会撤销已完成的外部操作。服务重启后，未确认结束的运行需先核查实际进程与环境，再释放占用资源。

详见[工作流使用说明](https://github.com/backinfile/ScriptBoard/blob/v2.12.0/docs/WORKFLOW_USAGE.md)。
