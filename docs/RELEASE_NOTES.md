# ScriptBoard v2.1.0

## Linux 服务安装与启动

- 修复 systemd socket 地址被按命令行参数引用的问题，确保 AI Host 与 Runner 的 Unix socket unit 能通过校验并正常激活。
- 安装时为 State Root 的父目录补充服务身份所需的目录遍历权限，避免低权限 Web 服务因无法进入状态目录而启动失败。

## 凭据与身份边界

- Broker 现在可按显式允许的服务身份验证并读取凭据主密钥，在保持 owner-only 权限检查的同时支持 Web 与 Broker 的安全协作。
- 新增 Unix 密钥所有者与权限回归测试，继续拒绝符号链接、错误所有者及向组或其他用户开放的凭据路径。

## 身份验证

- 修复页内提权挑战响应被通用错误脱敏逻辑改写的问题，保留已认证会话的当前 CSRF token，使密码提权对话框可以正常完成验证。
- 内部响应策略标记会在响应发送前移除，不会暴露给客户端。

## 升级

`v2.0.25` 已使用 updater protocol 2，可直接在“系统设置 → 更新”中升级到本版本。升级前仍建议备份 `config.yaml` 与 State Root；数据库成功由新版本打开后，不要再使用旧版本二进制访问同一 State Root。
