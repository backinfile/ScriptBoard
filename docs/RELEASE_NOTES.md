# ScriptBoard v2.14.0

## 新增与改进

- 自定义面板支持操作按钮、访问 Key 与四档可见性；流程卡支持参数化快捷执行、内联脚本、内置节点、节点及全局收尾步骤，保留执行历史。
- Registry 新增连接测试、只读/允许修改、镜像详情及批量清理预览；版本抽屉按创建时间从新到旧排列，未知时间置后。
- 可编辑记录支持最多 500 字的私有备注；公开面板不显示备注。
- Kubernetes 工作负载可自选显示列，查看完整镜像与容器上次启动时间；数据库连接浏览和备份访问更便捷。
- 文件上传逐项显示新建、覆盖或重命名结果；修复 HTTP 环境中工作流节点创建问题。
- 修复手机面板编辑遮挡、流程状态矛盾和英文文案遗漏；无效 YAML 就地提示错误、保留草稿并定位错误行。
- 优化镜像列表、批量范围、快捷执行表单和二次认证返回说明；修正主机指标统计与多平台镜像大小汇总。

## 升级与使用

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。

本版本会自动升级状态数据库以保存备注、面板流程和执行参数。流程配置参见[面板配置格式](./DASHBOARD-CONFIG-FORMAT.md)。

镜像仓库连接继续支持 HTTPS、HTTP 和显式跳过证书验证。跳过证书验证会增加中间人攻击风险，请仅在可信环境中使用。
