# ScriptBoard v2.6.0

## 新增功能

- Host Files 新增多选批量操作与日期排序，并可强制将无扩展名或未知扩展名文件按 TXT 安全预览。
- Redis 支持按操作选择数据库，并可在详情抽屉中编辑实例连接配置。
- MySQL 备份记录现在显示备份来源，便于区分和追踪逻辑备份制品。

## 功能修改与修复

- 修复 Host Files 分组快捷访问的导航行为，以及网站监控筛选栏的文本裁切、对齐和触发器高度问题。
- Linux 受管部署的宿主目录访问改由特权 Broker 提供，恢复对用户主目录的受控访问。
- MySQL 查询后端与备份制品统一经过 Broker 边界，修复受管部署中的查询和备份文件访问问题。
- 完善 MySQL、Redis 连接的安全与明文模式兼容性，修复 Redis 实例错误反馈、工具栏和窄视口抽屉布局。
- 修复批量 ZIP 写入失败被误报成功、快捷访问首次点击语义及重复路径校验等发布后审查问题。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
