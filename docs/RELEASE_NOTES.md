# ScriptBoard v2.15.0

## 新增

- 在「资源 → Git 项目」自选目录克隆仓库，或原地接入已拉取的仓库。支持打开目录、批量拉取和更新、强制更新、切换分支、丢弃已跟踪文件的改动及查看操作记录。
- 快捷执行支持分组和单项的 Git 前置更新。分组先更新，任一更新失败时停止执行。默认运行当前本地脚本，也可固定脚本版本。

## 升级

可在「系统设置 → 更新」安装此版本。使用 Git 项目前，请在主机上安装 Git。Windows 服务提示为便携安装时，请参阅 [v2.14.3 的升级说明](https://github.com/backinfile/ScriptBoard/releases/tag/v2.14.3)。
