# ScriptBoard v2.3.0

## 原子批量文件上传

- 文件页与任务页现可将多个文件作为一个批次上传；仅当整个批次通过校验后才统一写入，避免部分成功留下不完整结果。
- 上传过程显示当前文件、批次进度和提交阶段，传输完成后会明确提示正在校验并提交。
- 批次中的路径冲突与覆盖选择统一处理；无法安全完成时整批不写入，保持目录状态一致。

## 安全边界强化

- 加固外部接口的认证、签名、请求目标和转发头处理，避免不可信输入影响内部路由或越过既有访问边界。
- 收紧 Assistant Provider Proxy 的请求处理，并扩充输出上下文、归档路径、更新包与外部接口的安全回归测试。
- 安全模糊测试覆盖更多请求目标与归档路径边界，持续验证异常输入不会突破文件系统和网络访问约束。

## 监控与操作体验

- 操作菜单进入浏览器顶层显示，避免被父级裁剪或其他层叠上下文遮挡，并在桌面端与移动端保持可用位置。
- 重新整理共享实时刷新控件的层级、状态与响应式布局，使监控页面上的刷新节奏和当前状态更清晰。
- UFW 规则名称会作为原生注释持久化并在刷新后正确显示；Fail2Ban 详情汇总所有活跃 Jail 的当前与累计封禁，不再只读取 sshd。
- 自定义面板页签切换不再改变页签栏颜色，减少无关的视觉状态干扰。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份 `config.yaml` 与 State Root；数据库成功由新版本打开后，不要再使用旧版本二进制访问同一 State Root。
