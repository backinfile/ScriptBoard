# ScriptBoard v2.0.25

## 安全与身份验证

- TOTP 注册新增二维码展示，并将二维码图片的安全策略严格限定在注册流程中，减少手工录入密钥的成本。
- 对敏感 Web 操作加入页内提权验证，完善 Broker 与 Web 路由的会话授权边界，并统一维护者角色提示。
- Docker 配置仅向有权管理连接的角色展示，避免维护者看到不可操作的敏感配置入口。

## 变量、快捷运行与文件管理

- 变量支持类型与约束，可在执行前更明确地校验输入，降低错误参数进入脚本的风险。
- 快捷运行支持版本化管理，并移除已废弃的远程网站快捷运行路径。
- 文件回收站新增清理控制，抽屉交互、错误详情和角色引导同步优化。

## 镜像仓库与 Kubernetes

- 镜像选择器支持从仓库目录中选择镜像，并为目录展开增加数量与资源边界及对应安全回归测试。
- 修复 Kubernetes 本地连接工作流，统一 kubeconfig 打开失败的类型化错误与通用错误详情展示。

## 升级

`v2.0.24` 已使用 updater protocol 2，可直接在“系统设置 → 更新”中升级到本版本。升级前仍建议备份 `config.yaml` 与 State Root；数据库成功由新版本打开后，不要再使用旧版本二进制访问同一 State Root。
