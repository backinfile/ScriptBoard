# ScriptBoard v2.5.5

## 新增功能

- 自定义仪表盘的容器镜像卡片现在展示标签历史：按语义版本列出最新 5 个标签，并在存在更多版本时保留最早标签，便于快速查看版本跨度。
- 切换标签时，卡片会同步显示该标签的上传时间或 OCI 构建时间，以及对应的压缩下载大小。

## 功能修改与修复

- Registry 刷新失败时会完整保留最近一次成功获取的标签集合与逐标签元数据。
- 继续兼容升级前仅保存单个标签的自定义仪表盘快照。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
