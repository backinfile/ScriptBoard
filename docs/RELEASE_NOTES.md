# ScriptBoard v2.2.0

## 全新界面与操作体验

- 以新的纸张视觉体系重构应用界面，统一桌面端与移动端的排版、导航、详情展示和交互反馈。
- 概览页、任务、运行记录、文件、变量、计划任务、容器、Kubernetes、MySQL、安全面板和系统设置采用一致的抽屉式详情与编辑流程。
- 删除实例、数据库和计划等破坏性操作集中到对应编辑抽屉，减少列表页误操作，并让确认信息更贴近目标资源。

## 多机概览与主机可观测性

- 新增安全的多机概览，可通过受控 Fleet Token 汇总远端 ScriptBoard 节点的状态。
- 丰富 CPU、内存、磁盘、网络、系统信息和应用状态展示，并为不可用远端隐藏无法取得的详情。
- 主机保护状态、系统安全更新、登录与封禁记录、服务日志等特权读取统一通过 Broker 固定协议完成，Web 不再直接读取宿主特权数据。

## Kubernetes 与连接管理

- Kubernetes 监控现已集成连接管理，并可发现常见本地 kubeconfig 路径。
- 受管部署中的 kubeconfig 读取与集群访问移入 Broker，保持低权限 Web 与特权宿主访问之间的隔离。
- 连接配置明确保留安全、明文及协议支持时跳过证书验证的选择，不会静默改写用户的传输安全策略。

## 文件、脚本与快速执行

- 上传覆盖已被快速执行引用的脚本时，冲突确认会列出受影响项目，并可同步发布新的脚本摘要版本。
- 文件与任务详情、运行入口和移动端菜单经过重构，上传、预览、执行和结果反馈更清晰。
- 变量列表新增类型与元数据展示，Registry 监控补充镜像时间，并将空通配结果作为有效的空结果处理。

## 身份验证与安全边界

- MFA 注册改为可选；高风险操作仍要求近期认证，已配置 MFA 的账户继续使用第二因素，未配置账户使用当前密码。
- 安全面板按需加载高权限数据，并进一步分离采集器与 Web 权限，避免普通页面请求扩大宿主访问能力。
- 修复 Assistant 页面、SQLite 测试及多个视口覆盖层的稳定性问题。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份 `config.yaml` 与 State Root；数据库成功由新版本打开后，不要再使用旧版本二进制访问同一 State Root。
