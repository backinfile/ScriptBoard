# ScriptBoard v2.9.0

## 新增功能

- 新增“资源 → 灵感空间”：所有登录用户共同整理笔记、链接、待办、计时器和画板，支持自动保存、实时同步、模块排序和冲突处理。
- 画板支持多色画笔、直线、箭头、矩形、椭圆、局部橡皮和可编辑文字；可平移、调整视窗大小及撤销操作。
- 文件页新增“跳转”：输入路径，或搜索当前目录、子目录及全部主机位置，自动进入文件所在分页并高亮定位。
- 新安装使用一次性本机令牌设置管理员用户名和密码，完成后自动登录；支持密码文件配置和本机账号恢复。
- 可通过精确的父来源配置，将一个 ScriptBoard 嵌入另一个实例的自定义页签，保留目标登录态及界面语言。

## 功能修改与修复

- 新建空间保存响应丢失后可安全重试，不重复创建或误报冲突；真实的并发修改继续受到保护。
- 跨站 HTTPS iframe 内切换语言后，刷新、登录和导航均保留选择。
- 修复手机横屏下模块标题挤占超大画板绘图区的问题。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。

已有账号升级后继续直接登录。首次设置令牌位于 `state_root/secrets/initialization-token`，有效期为 24 小时；未完成设置时重启服务会生成新令牌。灵感空间由所有登录用户共享；已有开发版个人面板会迁入共享空间。

实例默认禁止嵌入。仅配置受信任的父来源；跨站登录需要目标实例使用 HTTPS，且浏览器允许第三方 Cookie。同站 HTTP 仍可使用。
