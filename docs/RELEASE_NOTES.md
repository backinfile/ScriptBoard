# ScriptBoard v2.13.0

## 改进

- 镜像仓库连接支持“只读”和“允许修改”模式，新连接默认只读；启用修改后可使用清理规则批量删除镜像。
- 镜像内容区支持多级命名空间导航：首次点击筛选镜像，再次点击当前节点展开或收起子目录，并保留各节点展开状态。
- 数据库与镜像仓库采用统一的连接侧栏和内容布局，改善窄屏显示；镜像仓库右上角可直接编辑当前连接。

## 升级与使用

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。

镜像仓库连接继续支持 HTTPS、HTTP 和显式跳过证书验证。跳过证书验证会增加中间人攻击风险，请仅在可信环境中使用。
