# ScriptBoard v2.4.2

## 数据库管理

- MySQL 和 Redis 现在使用统一的数据库工作区，连接、数据库与数据浏览更集中。
- 新增 MySQL 查询工作台，并支持浏览 Redis 键、类型、TTL 和内存占用。
- 数据库写入操作增加明确确认，连接与页面跳转也更加稳定。

## 任务与审批

- 快捷执行支持在分组内直接调整顺序，批量上传后保存的任务可继续正常运行。
- 一次性执行可以基于原始脚本和参数再次运行，并提供更清晰的运行详情与操作入口。
- 外部调用审批新增分类预览，可查看变量、日志、快捷执行和待上传文件的内容；待审批文件可先下载检查。
- 运行日志会稳定区分普通、警告和错误行，不再因输出速度不同而合并显示。
- 调整文件快捷访问编辑抽屉的操作层级，使页面主要操作更清晰。

## 页面与使用体验

- 可添加自定义页面页签，并在首次打开时加载内容。
- 文件和目录的固定操作保持一致，常用入口更容易整理。
- 改进登录页、文件预览、操作菜单、图标和页面布局在桌面与移动端的显示效果。
- 移除已停用的 AI 助手及相关设置。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
