# ScriptBoard v2.8.0

## 新增功能

- 新增“资源 → 文档”：收藏主机文件，按分组、排序和搜索管理常用文档，并直接预览或编辑；列表显示文件系统创建时间。
- 快捷访问拥有独立配置页，采用全宽分组列表，支持重命名、拖动排序、折叠和分组管理；文件页继续提供固定入口。
- Kubernetes 展示 NodePort、LoadBalancer 与 Ingress 外部访问入口，便于定位服务地址和端口。

## 功能修改与修复

- 从文档列表进入预览或编辑后，返回、取消及保存成功会保留文档来源页和搜索条件。
- Kubernetes 工作负载成员随刷新实时更新。
- 手动检查更新时同步刷新发布说明。
- 手动与自动计划执行统一遵循禁止重叠设置。
- MySQL 备份计划校验不可发生的日期，并防止并发重复领取同一轮任务。
- Redis 连接配置支持显式使用空密码，并正确处理 IPv6 地址。

## 升级

可从 `v2.0.25` 或更高版本在“系统设置 → 更新”中直接升级。升级前建议备份自定义配置与 ScriptBoard 状态目录。
