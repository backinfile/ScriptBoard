## 复查补漏

- 修复参数类型切换或默认值输入不完整后保存旧值的问题：保留输入文本，保存时按当前类型重新校验，错误显示在抽屉内。
- Entry 保存时重新解析当前表单中的参数，避免沿用此前的已解析值。
- 只读视图隐藏自定义节点编辑/删除按钮。
- 自定义节点和运行历史增加空列表提示。

新增回归先复现无效数字默认值仍能保存（失败），修复后通过；抽屉、日志串写、布局与连线回归均通过。定向 Go 工作流和模板测试通过。

## Entry 与快捷执行对齐

Entry 直接复用现有 qr-grid、qr、qr__head/meta/foot、action-menu 和运行状态条样式。顶部展示名称/工作流名称及更多菜单，中部展示绑定版本和最近五次运行状态，底部展示最近提交时间、总耗时与主运行按钮。总耗时含排队时间，提示中明确说明。点击状态在工作流内部打开对应历史记录，不进行页面导航。

外部 Chrome 验证桌面与 390px 窄屏、更多菜单编辑、运行记录跳转通过；整页导航计数为零。截图保留于 .scratch/workflow-deploy/entry-quickrun.png 和 entry-mobile.png。

## 运行状态、菜单与抽屉动效

- 运行历史参考 GitHub Actions 的运行列表、任务状态和日志组织方式：列表展示状态、名称、版本、操作者和时间；展开后左侧展示节点状态，右侧展示所选节点的错误、日志入口和折叠输出。保持真实工作流节点与进程数据，不生成不存在的 Git 提交信息。
- 参考：https://docs.github.com/en/actions/how-tos/monitor-workflows/view-workflow-run-history 与 https://docs.github.com/en/actions/how-tos/monitor-workflows/use-workflow-run-logs 。
- Entry 更多菜单恢复共享样式，含 Lucide 图标、左对齐、危险操作颜色；打开期间不由后台刷新重绘，选择操作后关闭。
- 抽屉统一项目 overlay tokens、620px 标准宽度（脚本/日志因内容使用 780px）、固定首尾与滚动正文。去除继承的页面入场动画，使用 130ms 滑入与 100ms 滑出，遮罩淡入淡出；支持减少动态效果、Escape 与遮罩关闭、未保存确认。
- scripts/test-workflow-history.cjs 覆盖节点选择、菜单跨轮询保持打开、遮罩关闭、窄屏无横向溢出和无整页导航；抽屉和布局回归通过。截图为 history-actions.png、history-mobile.png；本地部署和测试数据保留。
